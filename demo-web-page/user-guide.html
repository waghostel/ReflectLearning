ReflectLearning is designed to transform your learning materials into interactive, AI-powered educational experiences. Whether you're a student preparing for exams, a professional learning new skills, or an educator creating study materials, this guide will help you get started quickly and effectively.

rocket_launch Quick Start Guide

Follow these simple steps to create your first learning experience:

1

Set Up Your API Key

When you first open ReflectLearning, you'll see an API key modal. Paste your Google AI API key and click "Save". Your key is stored securely in your browser's local storage and never sent to external servers.

💡 Tip: Don't have an API key yet? Visit Google AI Studio to create one for free. The process takes less than a minute!

2

Upload Your Learning Materials

On the Upload Page, you have multiple options to provide your learning content:

  • Upload Files: Drag and drop PDFs, Word documents, PowerPoint presentations, or images
  • Paste Text: Copy and paste content directly into the editor
  • Voice Input: Speak your learning topics using the microphone feature
  • Search Topics: Enter a topic and let AI search the web for relevant information
  • Provide URLs: Paste links to articles, documentation, or web pages

⚠️ Note: You can combine multiple input methods! Upload a PDF, paste some notes, and add a URL—the AI will process everything together.

3

Refine Your Content

Once you've added all your materials, click the "Refine" button. The AI will:

  • Analyze and structure your content into logical chapters
  • Create a comprehensive learning report with clear headings
  • Generate Q&A sections for each chapter to test your understanding
  • Format everything in an easy-to-read, organized layout

Watch as your content streams in real-time—you'll see the AI building your personalized learning report right before your eyes!

4

Start Learning Interactively

Click "Start Learning" to enter the Main Page, where the real magic happens:

Technical Details

ReflectLearning is powered by Google's advanced AI technologies. This section provides technical insights into the AI models used, system architecture, and data handling practices.

🤖 AI Models & Capabilities

ReflectLearning leverages three powerful Google AI models to provide a comprehensive learning experience:

psychology Gemini Text AI

Model: gemini-flash-lite-latest and gemini-2.5-flash-native-audio-preview

Capabilities:

  • Content Analysis: Processes uploaded files (PDFs, documents, presentations) to extract and understand learning material
  • Content Generation: Creates structured learning reports with chapters, Q&A sections, and comprehensive explanations
  • Conversational AI: Powers the interactive tutor chat, providing context-aware answers to your questions
  • Web Search Integration: Can search the web for current information when "Search Grounding" is enabled
  • Content Refinement: Transforms raw content into well-organized, pedagogically sound learning materials
  • Chapter Rewriting: Regenerates chapter content with improved clarity and structure
  • Adaptive Learning: Adjusts responses based on conversation history and current chapter context

Usage: Gemini Text AI is the core intelligence behind content processing, chat interactions, and all text-based features in ReflectLearning.

image Imagen Image AI

Model: imagen-4.0-generate-001

Capabilities:

  • Image Analysis: Analyzes uploaded images to extract text, concepts, and visual information
  • Visual Content Understanding: Interprets diagrams, charts, and educational images to enhance learning materials
  • Image Generation: Creates custom visual aids and illustrations to support learning concepts (when requested)
  • Multi-modal Learning: Combines visual and textual information for comprehensive content understanding

Usage: Imagen AI processes image uploads and can generate visual learning aids to complement textual content.

mic Gemini Audio AI

Model: gemini-2.5-flash-native-audio-preview

Capabilities:

  • Voice Input: Transcribes spoken content into text for hands-free content input
  • Real-time Audio Streaming: Processes audio in real-time with native audio support for immediate transcription
  • Voice-based Tutoring: Enables voice interactions with the AI tutor for a more natural learning experience
  • Multi-language Support: Recognizes and transcribes speech in multiple languages
  • Reflection Mode: Powers voice-based reflection sessions where you can answer questions verbally

Usage: Gemini Audio AI enables voice input features throughout the application, making learning more accessible and interactive.

💾 Data Storage & Connectivity

storage Temporary Data Storage

ReflectLearning operates entirely in your browser with no persistent database or server-side storage:

  • Session-based Storage: All learning content, chat history, and chapters exist only in your current browser session
  • No Data Persistence: When you close the browser or refresh the page, all content is lost
  • Privacy-First: Your learning materials and conversations are never stored on external servers
  • Local Processing: Content is processed in your browser and sent directly to Google AI services
  • API Key Security: Your API key is stored locally in your browser's environment variables

💡 Tip: If you want to save your learning content, use the browser's print function (Ctrl+P / Cmd+P) to save chapters as PDF, or copy the content to an external document.

wifi Internet Connection Requirement

ReflectLearning requires a stable internet connection to function:

  • Real-time AI Processing: All AI features require active communication with Google's cloud services
  • Streaming Content: Content generation and chat responses stream in real-time over the network
  • Web Search: When "Search Grounding" is enabled, the AI searches the web for current information
  • Minimum Bandwidth: A broadband connection is recommended for optimal streaming performance
  • Offline Mode: The application cannot function without an internet connection

cloud Google AI Services Dependency

ReflectLearning is fully dependent on Google AI services for all intelligent features:

  • API Key Required: You must provide a valid Google AI API key to use the application
  • Service Availability: Application functionality depends on Google AI service uptime and availability
  • API Quotas: Usage is subject to Google AI API rate limits and quotas associated with your API key
  • Model Updates: The application benefits from Google's continuous model improvements and updates
  • Data Processing: All AI processing happens on Google's servers, not locally in your browser

⚠️ Important: Keep your API key secure and never share it publicly. Monitor your API usage through the Google AI Studio dashboard to avoid unexpected charges.

  • Check browser permissions: Click the lock icon in the address bar and enable microphone access
  • Ensure your microphone is connected and working (test in system settings)
  • Try refreshing the page and granting permissions again

📁 File Upload Fails

  • Verify the file format is supported (see "Supported File Formats" above)
  • Check file size (should be under 10MB)
  • Ensure you have a stable internet connection

  • Check your API quota hasn't been exceeded

⏳ Content Generation is Slow

  • Check your internet connection speed
  • Large or complex content takes longer to process
  • Google AI services may experience temporary slowdowns during peak usage
  • Try breaking large content into smaller chunks

💾 Lost My Content After Refresh

  • This is expected behavior - ReflectLearning doesn't save data between sessions
  • Use browser print (Ctrl+P / Cmd+P) to save content as PDF before closing
  • Copy important content to an external document for safekeeping
  • Consider keeping source materials accessible for regeneration

🖼️ Diagrams Not Rendering

  • Ensure JavaScript is enabled in your browser
  • Check that Mermaid.js CDN is accessible (not blocked by firewall/ad blocker)
  • Try refreshing the page
  • Clear browser cache and reload
