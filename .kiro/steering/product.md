## Product Overview

ReflectLearning AI Tutor is an interactive learning application that provides personalized educational experiences powered by Google's Gemini AI.

Users can upload learning materials (PDFs, documents, images) or provide text/URLs to generate comprehensive learning reports. The app creates structured chapters with Q&A sections, allows real-time chat with an AI tutor, and supports voice interactions for an immersive learning experience.

Key features:
- Upload and analyze learning materials
- Generate structured learning reports with chapters and Q&A sections
- Interactive AI tutor chat with context awareness
- Voice-based tutoring with native audio support
- Edit and rewrite chapter content
- Web search integration for up-to-date information
- Image generation for visual learning aids
